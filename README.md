# Home Services Booking SaaS (Vibe Coding)

A full‑stack SaaS platform that connects customers with professional home service providers (electricians, plumbers, cleaners, etc.).

The project follows the **Vibe Coding** workflow: AI‑assisted requirement analysis, design, code generation, testing, security hardening, CI/CD, and deployment.

## Stack
- **Frontend** – React.js + Vite, Tailwind CSS
- **Backend** – Python FastAPI
- **Database** – MySQL (SQLAlchemy ORM)
- **Auth** – JWT with role‑based access control
- **Payments** – Razorpay Test Mode (or Stripe sandbox)
- **File storage** – Cloudinary
- **CI/CD** – GitHub Actions, Vercel (frontend) & Render (backend)
